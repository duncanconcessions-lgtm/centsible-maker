## Official specs (from Anycubic)

| Spec | Kobra S1 (official) |
|---|---|
| Build volume | 250 × 250 × 250 mm |
| Construction | Fully enclosed CoreXY |
| Speed | Recommended 300 mm/s, max 600 mm/s |
| Acceleration | Recommended 10,000 mm/s², max 20,000 mm/s² |
| Hotend | Max 320 °C; 0.4 mm standard, 0.25/0.6/0.8 mm sold separately |
| Bed | Max 120 °C, PEI spring steel plate |
| Leveling | LeviQ 3.0 auto-leveling + Z-offset |
| Filaments listed | PLA, PETG, TPU, ABS, ASA |
| Noise (claimed) | ≤46 dB standard, ≤44 dB quiet mode (measured 1 m from front) |
| Camera | Built-in, 480P, AI spaghetti detection |
| Multicolor | Via ACE Pro (sold separately); up to two ACE Pros for 8 colors |
| Weight / size | 9.37 kg; 400 × 410 × 490 mm |

Note from Anycubic: TPU is single-color only and can't be used through the ACE Pro. Anycubic doesn't list active drying on the S1 itself.

Source: [Anycubic Kobra S1 official product page](https://www.anycubic.com/products/kobra-s1), accessed October 20, 2026. List price at that time was $349 (prices change often).
